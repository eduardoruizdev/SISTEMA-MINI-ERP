Sistema de ERP desenvolvido para centralizar e organizar processos administrativos de pequenas empresas.

A aplicação permite o gerenciamento de funcionários, usuários e tarefas, além do controle de fluxo de caixa, reunindo diferentes operações administrativas em uma única plataforma.

Funcionalidades
Cadastro e gerenciamento de funcionários
Cadastro e gerenciamento de usuários
Criação e gerenciamento de tarefas
Controle de entradas e saídas financeiras
Gerenciamento do fluxo de caixa
Consulta e organização dos dados cadastrados

Objetivo

O projeto foi desenvolvido com o objetivo de aplicar conhecimentos em desenvolvimento web, criação de APIs, integração entre frontend e backend, persistência de dados e gerenciamento de processos empresariais.
